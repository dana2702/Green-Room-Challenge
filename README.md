# Introduction
This is a thematic educational software project I developed during my military service to commemorate World Environment Day. Designed as an interactive learning experience for soldiers, the program focused on environmental protection and sustainability. I independently led the development—from concept and technical implementation to programming—using tools such as ActionScript 3 (AS3), Adobe Animate, and Adobe Flash. The educational content was sourced from the media team of the Education Corps, where I served, and I collaborated with a graphic design team to complete the project.


# Explanation
**Since this is a military product, I cannot share the code or the product itself. Therefore, I attached a demonstration video of this educational software at the bottom of this file.**

The interactive experience was structured as a virtual "room," where each wall represented a different educational activity related to environmental awareness.
The virtual room included the following four interactive walls:

**Wall 1: "Watch Out for Plastic!"**

A short educational video that highlights the dangers of plastic pollution and its long-term impact on the environment.

**Wall 2: "Bin It Right!"**

A drag-and-drop sorting game where users must place different types of waste into the correct recycling bins. The game teaches proper recycling habits in a fun and visual way.

**Wall 3: "Sea of Bottles"**

An interactive game where users clean up a polluted ocean by removing virtual plastic waste. As they clean, hidden facts and surprises are revealed from within the trash, raising awareness about ocean pollution.

**Wall 4: "Trash or Treasure?"**

A personality quiz-style game (flowchart-based) that helps users discover how eco-friendly their habits are. At the end of the quiz, users receive one of two humorous results: “Clean” or “Trash.”

This project aimed to deliver environmental education in a fun, gamified format that encouraged engagement and reflection.
